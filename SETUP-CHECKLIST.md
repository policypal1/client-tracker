# 5-minute deployment checklist

- [ ] Create Supabase project
- [ ] Run `supabase/schema.sql` in Supabase SQL Editor
- [ ] Push this entire folder to a GitHub repo
- [ ] Import the repo into Vercel
- [ ] Add `SUPABASE_URL` in Vercel Environment Variables
- [ ] Add `SUPABASE_ANON_KEY` in Vercel Environment Variables
- [ ] Redeploy Vercel
- [ ] Open the live site
- [ ] Create your account / sign in
- [ ] Set the monthly amount for The One Clear Choice Auto Glass
- [ ] Set the monthly amount for ZH Homes
- [ ] Start adding next actions to each client
